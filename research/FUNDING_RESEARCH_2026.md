## 2. 즉시 행동 가능한 사업 (신청 가능)

### 2-1. 콘텐츠 스타트업 AC 연계지원 ⭐ 최우선

| 항목 | 내용 |
|------|------|
| **마감** | **2026.04.08(수) 11:00** |
| **기관** | 한국콘텐츠진흥원(KOCCA) |
| **지원금** | 기업당 최대 **9,000만원** + 우수기업 투자 연계(1억원+) |
| **선정 규모** | 18개사 |
| **자격** | 창업 7년 이하 콘텐츠 기업 (법인/개인사업자) |
| **평가** | 서면평가(40%) + 발표평가(60%) |
| **협약기간** | 2026.05 ~ 2026.11 |
| **접수** | 콘진원 PMS 또는 e나라도움 온라인 접수 |

**적합성 분석:**
- AI 기반 소설 퍼블리싱 = "콘텐츠 × 기술 융합" 분야에 정확히 해당
- DeerDevil 프로토타입 존재 = 기술 검증 증빙 가능
- 창업 3년 이하 기업은 경진대회 참가 혜택 추가

**제약사항:**
- 사업자등록 필요 (법인 또는 개인사업자)
- 사업자등록이 없으면 신청 불가

**필요 서류:**
- [ ] 사업계획서 (사업 내용, 목표, 일정)
- [ ] 예산 세부 내역서
- [ ] 팀 역량 증빙 (경력, 포트폴리오)
- [ ] 사업자등록증
- [ ] 국세/지방세 완납증명서

## 3. 마감됐지만 2027년 반드시 준비할 사업

### 3-1. AI 콘텐츠 제작지원 — 진입형 (콘텐츠진흥원) ⭐ 최적합

| 항목 | 내용 |
|------|------|
| **2026 마감** | 2026.03.06 (마감) |
| **예상 재공고** | 2027년 2~3월 |
| **지원금** | 과제당 최대 **2억원** (국고 90%, 자부담 10%) |
| **협약기간** | 약 7.5개월 |
| **총 예산** | 198억원 (진입형 24개 + 선도형 10개 + 협력형) |

**왜 최적합인가:**
- **"콘텐츠 플랫폼/솔루션 실증 제작"** 트랙이 별도로 존재
- Claude API 기반 테마 생성 파이프라인 = AI 콘텐츠 제작 기술
- 플랫폼 개발 + 실제 소설 퍼블리싱 실증까지 요구 = ProjectGrimoire 구조와 정확히 일치
- 단순 범용 AI 서비스 적용은 제외 → Grimoire의 독자적 파이프라인을 강조해야 함

**2027년 준비 사항:**
- [ ] 데모 버전(MVP) 완성 — DeerDevil 수준 이상의 실동작 프로토타입
- [ ] 실증 결과물 — 최소 2~3명 작가의 실제 퍼블리싱 사례
- [ ] 사업계획서 초안 (기술 혁신성 + 시장성 + 사업화 계획)
- [ ] 법인 설립 (개인사업자도 가능하나 법인이 유리)

## 9. 핵심 결론

1. **사업자등록이 가장 큰 분기점** — 있으면 콘텐츠 스타트업 AC 연계(4/8), 없으면 모두의 창업(수시)
2. **2027년이 본격 기회** — 예비창업패키지(무상 1억) + AI 콘텐츠 제작지원(2억)이 가장 적합
3. **지금 할 일**: MVP 완성 + 실증 사례 + 사업계획서 초안 준비
4. **정부 지원 총 예산 3.4조원, 508개 사업** — ProjectGrimoire에 매칭되는 사업이 분명히 존재
