## 1. 포지셔닝 제안

### 제미나이 원문

> "우리 서비스는 작가들이 쓰는 레디맥(Readymag) 같은 겁니다"
>
> 레디맥이 디자이너들의 가려운 곳(코딩은 모르지만 쩌는 인터랙션을 원함)을
> 긁어주어 성공했다면, 그리무아르는 작가들의 가려운 곳
> (웹 개발은 모르지만 내 세계관을 쩌는 백과사전이나 테마로 전시하고 싶음)을
> 긁어주면 됩니다.

**핵심 가치:** 기성 플랫폼에 종속된 부품이 아닌, 작가 고유의 세계관(Universe)을
독립적인 미학으로 전시하는 '웹상의 갤러리' 제공.

- 그리무아르 쇼룸 백링크 자동 삽입 → 바이럴

## 6. Claude 의견

### 동의하는 부분

- **"작가들의 레디맥"은 매우 강력한 피치.** 한 문장으로 서비스 본질을 설명할 수 있다.
- **Freemium 모델** — 코어 무료 + RAG Pro 유료는 현재 아키텍처와 자연스럽게 맞물린다.
  이미 크레딧 시스템이 구축되어 있어서 구독 전환 비용이 낮다.
- **A24식 큐레이션** — 설정집/유물/비하인드를 세계관으로 묶는 아이디어는
  현재 `works > episodes` 2레벨 구조에 `artifacts` 레벨을 추가하면 구현 가능.

### 주의가 필요한 부분

- **Readymag/Cargo식 자유 레이아웃** — 현재 아키텍처는 테마 JSON → CSS Variables로
  "분위기"를 제어하는 방식. 캔버스 자유배치는 아키텍처를 근본적으로 바꿔야 한다.
  Phase 1에서는 "테마 커스터마이징 깊이 강화"로 접근하고,
  캔버스 에디터는 Phase 2+ 검토가 현실적.

- **Universe Consistency Guard** — RAG 인프라는 준비되어 있지만 (pgvector, 임베딩),
  "서사 일관성 검증"은 프롬프트 엔지니어링 + 평가 지표 설계가 핵심.
  MVP로 "캐릭터 이름/설정 불일치 탐지" 수준부터 시작하는 게 좋다.

- **Community Multicasting** — 기능적으로 단순하지만 커뮤니티별 포맷 대응이 번거로움.
  MVP는 "HTML 스니펫 복사 + 백링크 포함" 정도로 충분.

### 우선순위 제안

현재 기획서(PLANNING_GRIMOIRE.md)의 Phase 1 완료가 먼저다.
이 제안은 Phase 2 기획에 반영하는 것이 적절하다.

| 즉시 반영 | Phase 2 검토 |
|----------|-------------|
| "작가들의 레디맥" 포지셔닝 문구 | 자유 레이아웃 캔버스 |
| Freemium 모델 구체화 | Universe Consistency Guard |
| A24식 Artifacts 데이터 모델 설계 | Community Multicasting |
