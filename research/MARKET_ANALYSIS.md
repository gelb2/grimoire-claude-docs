## 1. TAM / SAM / SOM 시장 규모

### TAM (전체시장) — 국내 웹소설 시장

- **2024년 기준 약 1조 3,500억 원** (한국출판문화산업진흥원, 2024)
- 2022년 1조 390억 원 대비 약 **30% 성장**
- 2025~2026년 **약 2조 원대** 전망
- 웹소설+웹툰 포함 콘텐츠 매출 중 웹소설 비중 약 45.3%

**성장 동인:**
- 모바일 기기 보급 + 비대면 콘텐츠 소비 확대
- 웹소설 → 웹툰/드라마/영화 IP 확장 (미디어 믹스)
- MZ세대의 짧은 콘텐츠 소비 패턴

### SAM (유효시장) — 인디/자체 퍼블리싱 작가 세그먼트

ProjectGrimoire는 대형 플랫폼(카카오페이지, 네이버시리즈)과 **직접 경쟁하지 않는다.**
타겟은 "자신만의 시각적 공간에서 독립적으로 퍼블리시하려는 작가"이다.

- 국내 웹소설 작가 약 **20만 명** (활동 기준, 2022년 실태조사 기반 업계 추정치 — 공식 집계 미존재)
- 이 중 대형 플랫폼 전속이 아닌 인디/비전속 작가 약 **5~8만 명** 추정
- 해외 유사 시장: Substack (뉴스레터 기반 소설 연재), Wattpad (무료 연재), Royal Road
- SAM 규모: 인디 작가 5만 명 × 연 평균 지출 가능액 10~30만 원 = **연 50~150억 원**

### SOM (초기목표시장) — 1차 타겟

- **순문학/단편소설/장르문학 인디 작가** 중 자체 브랜딩 욕구가 있는 작가
- 추정 규모: **1,000~3,000명**
- Pro 플랜 기준 월 9,900원 × 1,000명 = **월 990만 원 (연 1.2억)** *(가격 미정, 추정치)*
- Premium 기준 월 29,000원 × 500명 = **월 1,450만 원 (연 1.7억)** *(가격 미정, 추정치)*

## 3. Porter's 5 Forces

### 산업 내 경쟁 (경쟁강도: **낮음~중간**)

- 대형 플랫폼(카카오/네이버/리디)은 **대중 소비** 시장 장악
- "작가 브랜딩 + 시각적 독립 공간" 시장은 **사실상 경쟁자 부재**
- Grimoire는 대형 플랫폼의 **보완재** 포지션 (경쟁이 아닌 공존)

→ **대응:** 대형 플랫폼에서 독자를 확보한 작가가 "자기만의 공간"을 원할 때 선택하는 프리미엄 도구로 포지셔닝.

### 신규 진입자 위협 (낮음)

- AI 테마 생성 + 소설 특화 파서 + 멀티테넌트 아키텍처의 기술적 진입장벽
- 소설 퍼블리싱 도메인 지식 필요 (블록 시스템, 타이핑 애니메이션, 시리즈 네비게이션 등)
- 대형 플랫폼은 이 시장에 관심이 낮음 (수익 규모가 작아 매력도 낮음)

→ **대응:** 작가 데이터 축적(테마, 작품, 독자 데이터)으로 전환 비용 형성.

### 대체재 위협 (중간)

- WordPress/Notion/개인 블로그로 자체 퍼블리싱 가능
- Readymag/Squarespace 등 웹사이트 빌더로 유사 결과물 제작 가능
- **AI 소설 생성 플랫폼 급증** (단편.ai, 픽노블, 한줄 등) — 다만 이들은 "AI가 글을 쓰는" 도구로 Grimoire의 "작가가 글을 쓰고 AI가 공간을 꾸미는" 포지션과 다름
- 다만 소설 특화 기능(에피소드 뷰어, 타이핑 이펙트, 시리즈 네비) 부재

→ **대응:** 범용 도구로는 구현 어려운 소설 특화 경험(타이핑 애니메이션, 블록 기반 렌더링, AI 테마)에 집중. "AI 창작" vs "AI 브랜딩"의 명확한 포지셔닝 차별화.

### 공급자 교섭력 (중간)

- Claude API (Anthropic), Azure 인프라 의존
- API 가격 인상 시 원가 구조 직접 영향 (현재 테마 1건 ≈ ₩14)
- 안전 마진 기준 3배 이상 확보됨 (₩100 > ₩17.5 × 3)

→ **대응:** 시맨틱 캐싱으로 API 호출 50% 절감. 오픈소스 LLM 폴백 아키텍처 검토.

### 구매자 교섭력 (중간~높음)

- 인디 작가는 가격 민감도 높음
- 무료 대안(WordPress, 블로그) 존재
- SaaS 구독 특성상 전환 비용 낮음

→ **대응:** 무료 플랜으로 진입 장벽 제거 + 테마/작품 데이터 축적으로 자연스러운 락인. 작가의 독자 관계가 플랫폼에 귀속되는 구조 지양(작가 독립성 강조).

## 4. SWOT 분석

### S (강점)

- **AI 테마 생성**: 텍스트 설명만으로 시각적 공간 자동 생성 — 유일무이한 기능
- **소설 특화**: 타이핑 애니메이션, 블록 기반 렌더링, 에피소드 뷰어 등 범용 도구 대체 불가
- **멀티 포맷 파서**: MD/TXT/DOCX/HWP 원고 자동 파싱 → 블록 데이터 변환
- **작가 독립성**: 수수료 0%, 자체 URL 공간, 작가 소유 브랜딩
- **기술 완성도**: MVP 수준을 넘어 3환경(dev/inhouse/production) 운영 중. ESLint 0건, 테스트 전부 통과 상태 (실제 수치는 각 레포 `npm test` 실행으로 확인)

### W (약점)

- **독자풀 부재**: 대형 플랫폼처럼 자체 독자 유입 채널 없음
- **브랜드 인지도**: 신규 서비스로 작가 커뮤니티 내 인지도 0
- **1인 개발**: 개발/운영/마케팅 리소스 제한
- **수익 검증 미완**: 결제 연동 미완료, 실제 유료 고객 0

→ **보완:** 초기 10명 작가 대상 무료 베타 프로그램 운영. 작가 커뮤니티(문피아 자유게시판, 브런치, 트위터 작가계) 타겟 마케팅. 사슴악마(deerdevil) 작가공간을 쇼케이스로 활용.

### O (기회)

- **인디 작가 시장 성장**: 대형 플랫폼 수수료(30~50%)에 불만인 작가 증가
- **AI 콘텐츠 도구 트렌드**: AI 기반 크리에이터 도구 시장 급성장
- **한국 웹소설 글로벌 확장**: K-웹소설 해외 진출 → 다국어 지원 시 글로벌 확장 가능
- **대형 플랫폼 전속 계약 논란**: 불공정 계약 이슈 → 독립 퍼블리싱 수요 증가
- **Kindle Vella 종료 (2025.02)**: 연재 소설 인디 퍼블리싱 시장에 공백 발생

→ **활용:** "수수료 0% + 자기만의 공간"을 핵심 메시지로 작가 커뮤니티 어필.

### T (위협)

- **대형 플랫폼 기능 확장**: 카카오/네이버가 작가 커스터마이징 기능 추가 가능성
- **범용 AI 도구 발전**: ChatGPT/Claude 직접 사용으로 테마 JSON 생성 가능 (DIY)
- **AI 소설 생성 플랫폼 확산**: 단편.ai/픽노블 등 AI가 직접 글을 쓰는 서비스 증가 — "인간 작가"의 존재 가치 자체에 대한 인식 변화 가능성
- **작가 이탈**: 독자 유입이 되지 않으면 작가가 대형 플랫폼으로 복귀
- **인프라 비용 상승**: Azure/Anthropic API 가격 인상 리스크

→ **대비:** 대형 플랫폼이 제공하기 어려운 "작가별 독립 URL + 시각적 브랜딩"에 집중. 독자 유입 지원(SEO, 소셜 공유, 탐색 페이지) 강화.

- 작가 커뮤니티 (문피아 자유게시판, 브런치, 트위터 작가계) 타겟 홍보
- Product-Market Fit 검증

### 중기 (4~6개월): 유료 전환 + 커뮤니티

- 탐색 페이지 SEO 최적화 → 독자 유입 채널 확보

- BEP 달성 목표 (40~50명)

### 후기 (7~12개월): 확장

- IP 확장 지원 (EPUB 내보내기, 인쇄 조판 등)

- 테마 마켓플레이스 (작가 간 테마 공유/판매)
