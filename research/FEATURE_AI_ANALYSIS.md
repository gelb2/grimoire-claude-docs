## 1. 콘셉 배경

### 원래 영감

Claude 맥 앱의 **프로젝트 → 채팅** 기능에서:
- 사슴악마 원고 파일들을 프로젝트에 올려놓고
- 채팅에서 "캐릭터 성격 변화가 있나?", "이질감 있는 부분은?", "조형 수준은?" 질문
- Claude가 전체 원고 맥락을 참조해서 정밀한 분석/보정 제공

**이 경험을 그리모어 플랫폼에 내장하겠다는 것.**

### 그리모어에서의 구현 방식

Claude 맥 앱은 프로젝트 파일 전체를 컨텍스트 윈도우에 넣지만, 그리모어는:

```
원고 → 청킹(800자) → OpenAI 임베딩 → pgvector 저장
                                          ↓
새 에피소드 → 임베딩 → 유사 청크 검색(top 15) → Claude에 맥락으로 전달
                                                    ↓
                                          분석 결과 (점수 + 이슈 + 제안)
```

**핵심 차이:** Claude 맥 앱은 전체 원고를 넣지만, 그리모어는 **RAG로 관련 부분만 선별 → 비용 절감 + 긴 시리즈도 분석 가능.**

### 분석 유형

| 유형 | 검사 대상 | 예시 |
|------|----------|------|
| consistency | 설정 모순, 시간대 불일치, 이미 해결된 복선 재등장 | "ep1에서 죽은 캐릭터가 ep3에서 등장" |
| tone | 문체 변화, 서술 톤 일관성, 어휘 수준 | "고전적 문체에서 갑자기 현대어 사용" |
| character | 성격 변화, 말투 일관성, 행동 동기 | "내성적 캐릭터가 갑자기 외향적으로 변함" |

## 3. Claude 맥 앱 프로젝트 채팅과의 차이 + 보완 방향

### 현재 차이점

| 항목 | Claude 맥 앱 | 그리모어 현재 |
|------|-------------|-------------|
| 맥락 제공 | 프로젝트 파일 전체 | RAG 상위 15개 청크 |
| 대화 | 자유 형식 채팅 | 구조화된 3가지 분석 |
| 비용 | 구독 무제한 | API 호출당 과금 |
| 시리즈 크기 | 200K 토큰 제한 | 제한 없음 (RAG) |

### 보완 방향: "AI 작가 어시스턴트" 채팅

**Claude 맥 앱의 프로젝트 채팅 경험을 재현하려면:**

1. **자유 형식 채팅 인터페이스** — 구조화된 분석 외에 "이 캐릭터의 동기가 뭐야?", "3장 마지막 장면을 다시 써줘" 같은 자유 질문
2. **전체 작품 맥락 제공** — RAG로 관련 청크를 자동 검색해서 Claude에 맥락으로 전달
3. **대화 히스토리** — 이전 질답을 기억 (세션 기반)

```
작가가 채팅에 질문 입력
  → 질문을 임베딩
  → pgvector에서 관련 청크 검색 (top 15)
  → Claude에 전달: [시스템 프롬프트] + [관련 청크] + [대화 히스토리] + [질문]
  → 응답을 스트리밍으로 반환
```

**이건 현재 RAG 인프라 위에 채팅 UI + 히스토리 관리만 추가하면 됨.**

### Phase 2: 자동화 + UI
- [ ] 에피소드 업로드 시 자동 인덱싱 (백그라운드)
- [ ] 대시보드에 "작품 분석" 탭 (점수 시각화, 이슈/제안 표시)
- [ ] 분석 결과 DB 저장 (재조회 가능)

## 5. 기술 스택

| 컴포넌트 | 기술 | 파일 |
|---------|------|------|
| 텍스트 청커 | 자체 구현 (800자, 한국어) | `src/lib/rag/chunker.ts` |
| 임베딩 | OpenAI text-embedding-3-small | `src/adapter/outbound/embedding/` |
| 벡터 DB | pgvector (PostgreSQL) | `src/adapter/outbound/vector/` |
| 분석 로직 | Claude API + 구조화 프롬프트 | `src/lib/rag/novel-analyzer.ts` |
| UseCase | NestJS Hexagonal | `src/application/analysis/` |
| API | REST (JWT 인증) | `src/adapter/inbound/http/controller/analysis.controller.ts` |
