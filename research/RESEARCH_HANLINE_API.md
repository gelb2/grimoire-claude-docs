## 6. "작품 설정 확인" 모달 (AI 생성 결과)

AI가 시놉시스 기반으로 자동 생성하는 항목:

| 필드 | 설명 |
|------|------|
| 작품 제목 | 사용자 입력 |
| 장르 | 문학소설 (드롭다운) |
| 작품 생성 언어 | 한국어 (드롭다운) |
| 텍스트 생성 모델 | 기본값 (서버) — 드롭다운으로 변경 가능 |
| 이미지 생성 모델 | 기본값 (서버) — 드롭다운으로 변경 가능 |
| 전체 회차 | 100 (수치 입력) |
| 회차별 글자수 | 수치 입력 |
| 로그라인 | AI 자동 생성 |
| 등장인물 | AI 자동 생성 (이름, 역할 + 추가 버튼) |
| 세계관 | AI 자동 생성 (시대/배경, 기술수준, 마법체계, 정치사회, 톤, 테마, 피해요소) |
| 문체 | AI 자동 생성 (기·승·전·결 구조) |

### AI 생성 구조 — 세계관 상세

```
시대·배경: 전래동화의 시대적 배경을 차용한 가상의 고대/중세
기술 수준: 철기 시대 수준의 농경 및 수렵 사회
마법·초자연 체계: 인간의 욕망과 죄책감을 먹고 자라는 악마적 마법 체계
정치·사회 구조: 촌장 중심의 폐쇄적 촌락 공동체와 천상의 질서(선녀)
작품 톤: 어둡고 서늘하며, 심리적 압박감과 윤리적 불쾌감
테마: 인간의 이기심과 자기합리화, 폭력으로서의 은혜와 구원
피해야 할 요소: 마법 전투 씬, 사이다식 복수나 명쾌한 권선징악
```

> 참고: 사슴악마 시놉시스를 입력하여 생성한 결과.

## 7. Studio 핵심 기능 (2026-03-31 스크린샷 기반)

### 7-1. AI Assistant (채팅)
- 우측 패널에 채팅 UI
- 작품 컨텍스트 유지 (사슴악마 시놉시스/세계관 기반)
- AI 모델 선택 드롭다운 (Claude-Sonnet-4.6 등)
- 제안 버튼: "전체 시놉시스의 갈등 구조가 선명한지 분석해줘", "세계관에서 아직 전형적으로 느껴지는 부분을 짚어줘"
- 사용자가 자유 질문 가능 ("선녀가 나무꾼을 파멸시키기 위해 심계를 했다는 사항을 추가 해보는건 어때?")

### 7-2. 다음화 생성
- 모달: "방향성 직접 지정" (자유 텍스트) + "AI 제안 선택" (AI 추천 방향)
- "AI 자동 생성" 버튼 — 크레딧 소비 추정
- AI 추천 생성 버튼 별도

### 7-3. 장면 이미지화 (삽화 생성)
- 이미지 스타일 드롭다운:
  - 웹툰 / 만화
  - 폴라로이드 / 로모
  - 포토리얼
  - 수채화
  - 픽셀아트
  - 수묵화
- 프롬프트 자동 생성 (소설 본문 기반 영어 프롬프트)
- "현재 장면 이미지 생성" 버튼

### 7-4. 에디터 화면 구조
- 좌측: 회차 목록 (전체 시놉시스, 1화 숲의 그림자)
- 중앙: 본문 에디터 (직접 편집 가능) — 2,365자 표시
- 하단 탭: "다음화 생성" / "장면 이미지화" / "AI Assistant"
- 상단: "배포하기" 버튼 (빨간색)
- 좌측 하단: 8 크레딧 (사용 후 28→8로 감소)

### 7-5. 크레딧 소비 관찰
- 작품 설정 생성 시: 크레딧 28 → 생성 후 크레딧 감소
- 현재 8 크레딧 남음 (20 크레딧 소비 추정)
