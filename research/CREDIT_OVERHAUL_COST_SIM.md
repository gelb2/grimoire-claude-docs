## 1. 채팅 턴별 토큰 분포 시나리오 (가정)

채팅 1턴 시스템 프롬프트는 `ai-analysis-spec.md §6-2`로 무겁다: 절대규칙 + 에피소드 매니페스트 + 프로젝트 메모리 + 작품 지침 + **RAG 청크 top 25** + 대화 히스토리 10개 + 질문. RAG 청크(800자/청크)가 input의 지배 변수다.

**[가정 A1]** 턴별 input/output 토큰 분위수 (RAG 청크 수 + 답변 길이로 시나리오화):

| 분위수 | 시나리오 | input tok | output tok | 근거(가정) |
|---|---|---|---|---|
| P50 | 보통 질문 (청크 ~8개 + 보통 답변) | 1,500 | 600 | 매니페스트·메모리·지침 ~600 + 청크 8×~100 + 히스토리·질문 |
| P90 | 컨텍스트 포함 질문 (청크 ~20개) | 5,000 | 1,200 | RAG top 근접, 긴 답변 |
| P95 | 긴 컨텍스트 (청크 25개 풀 + 긴 답변) | 9,000 | 2,000 | top 25 전량 + 장문 답변 |
| P99 | 최대 맥락 (메모리·히스토리 비대 + 최장 답변) | 16,000 | 3,000 | 누적 히스토리 비대 케이스 |

### 1-1. 분위수별 AI 원가 (환율 ₩1,474, 수수료 제외 순 AI 원가)

| 분위수 | Sonnet 4.6 (USD / ₩) | Haiku 4.5 (USD / ₩) | Haiku 절감 |
|---|---|---|---|
| P50 | $0.01350 / **₩19.90** | $0.00450 / **₩6.63** | 67% |
| P90 | $0.03300 / **₩48.64** | $0.01100 / **₩16.21** | 67% |
| P95 | $0.05700 / **₩84.02** | $0.01900 / **₩28.01** | 67% |
| P99 | $0.09300 / **₩137.08** | $0.03100 / **₩45.69** | 67% |

> 계산식: `(in×단가_i + out×단가_o) × 1474`. Sonnet $3/$15·M, Haiku $1/$5·M.
> ai-cost-table §3-4의 "채팅 1턴 ₩16.2"는 input 2,000/output 800 가정 — 본 시뮬 P50(₩19.9)과 P90(₩48.6) 사이. **기존 ₩16.2 가정은 RAG top 25 풀 적재를 과소평가**. P95 기준 실제는 5배 이상.

**핵심 발견**: Sonnet P95(₩84) / P99(₩137)는 베스트 크레딧 판매가 ₩100 1개로 차감 시 안전배수 **1.2×·0.73×** → **§0 정면 위반**. 정수 1크레딧 채팅 과금이 적자 구조라는 계획서 §1-2 진단을 수치로 확정.

## 2. 디노미네이션 단위별 검증

1크레딧을 N포인트로 분할. **포인트 단가 = 크레딧 개당 단가 ÷ N**. 가장 보수적인 베스트 패키지(개당 ₩100, 개당 수수료 ₩11.7) 기준.

### 2-1. 비율별 포인트 판매가 & 채팅 P95 차감

| 비율 | 1pt 판매가 | P95 차감(원가×3 충족 최소 올림) | 실효 차감액 | 실효 안전배수 |
|---|---|---|---|---|
| 1:100 | ₩1.0000 | 253 pt | ₩253.00 | 3.01× ✅ |
| 1:1,000 | ₩0.1000 | 2,521 pt | ₩252.10 | 3.00× ✅ |
| 1:10,000 | ₩0.0100 | 25,206 pt | ₩252.06 | 3.00× ✅ |

> 채팅 차감 = `ceil(AI원가 × 3 ÷ 1pt판매가)` pt. P95 원가 ₩84.02 기준.

### 2-2. 반올림 오차 누적 적자 리스크 — **핵심 판정 지점**

올림(ceil) 차감이라 큰 턴은 항상 마진이 3× 이상으로 안전. **위험은 "최소 1pt 차감" 정책일 때 짧은 턴**이다.

**[가정 A2]** 짧은 질문 P10 = input 300 / output 150 → Sonnet 원가 **₩4.64**, §0 충족 최소 차감액 = ₩13.93.

| 비율 | 1pt 차감 시 차감액 | 짧은질문 §0 충족 필요 최소 pt | 판정 |
|---|---|---|---|
| 1:100 | ₩1.00 | 14 pt | 1pt 차감 시 **적자** (₩1 < ₩13.93). 단 14pt 차감 강제하면 OK |
| 1:1,000 | ₩0.10 | 140 pt | 1pt 차감 시 적자. 140pt 차감 강제 시 OK |
| 1:10,000 | ₩0.01 | 1,393 pt | 1pt 차감 시 적자. 1,393pt 차감 시 OK |

**결론**: 반올림 적자는 **비율의 문제가 아니라 차감 정책의 문제**다. 어느 비율이든 "`ceil(AI원가 × 3 ÷ 1pt판매가)`로 차감" 규칙을 강제하면 §0 안전. "턴당 최소 1pt 고정" 같은 단순 정책은 모든 비율에서 적자.

- **1:100** — 1pt = ₩1. 입자도가 거칠어 P10(원가 ₩4.64×3=₩13.93)을 14pt로 표현 → 최대 ₩0.07(0.5%) 올림 오버차지. 허용 범위지만 작은 턴 표현력 부족.
- **1:1,000** — 1pt = ₩0.1. 올림 오차 P95에서 ₩0.9(0.36%), 짧은 턴도 ₩0.07 이내. **표현력·오차·인지부담 균형 최적**.
- **1:10,000** — 1pt = ₩0.01. 오차 무시 수준이나 "25,206pt 차감" 표시가 사용자 인지 부담(계획서 §3-A 표시 UX 우려). 회계 정밀도 과잉.

> 디노미네이션 자체는 §0 중립: 단가와 차감을 동일 비율 N으로 나누므로 안전배수 불변. 적자 리스크는 **올림 처리 1회뿐**이고 올림은 항상 사업자에게 유리(과소차감 불가). **누적 적자는 구조적으로 발생 불가** — 단, 차감액을 ceil이 아닌 round/floor로 구현하면 floor에서 건당 최대 1pt 과소차감 → 이건 코드 규칙으로 **ceil 강제** 필요(S Phase 구현 주의).

**권고 비율: 1:1,000.**

## 3. 구독 fair-use 한도 역산 (옵션 C)

조건: **월 한도 내 누적 채팅 AI 원가 ≤ (구독료 − 결제수수료) ÷ 3**.
구독 결제수수료 = Polar 2.9% + ₩442 고정 (월 1건).

| 플랜 후보 | 구독료 | 수수료 | 순수익 | budget(÷3) | Sonnet P50 한도 | Sonnet P95 한도 | Haiku P50 한도 | Haiku P95 한도 |
|---|---|---|---|---|---|---|---|---|
| Pro 저 | ₩4,900 | ₩584 | ₩4,316 | ₩1,439 | **72턴** | **17턴** | 216턴 | 51턴 |
| Pro 고 | ₩9,900 | ₩729 | ₩9,171 | ₩3,057 | **153턴** | **36턴** | 460턴 | 109턴 |
| Premium 저 | ₩12,900 | ₩816 | ₩12,084 | ₩4,028 | **202턴** | **47턴** | 607턴 | 143턴 |
| Premium 고 | ₩19,900 | ₩1,019 | ₩18,881 | ₩6,294 | **316턴** | **74턴** | 948턴 | 224턴 |

> 한도 = `budget ÷ 분위수 원가`. P50/P95는 §1-1 표 값.

**해석**:
- "Sonnet P95 한도"가 진짜 안전선(헤비유저가 매 턴 긴 컨텍스트를 쓰는 최악 케이스). Pro 저(₩4,900)는 P95 기준 **17턴/월**까지만 §0 안전 — 너무 빠듯하다. 헤비유저가 P95 18턴째에 적자 진입.
- 현실 사용은 P50~P90 혼합. **혼합 가정(P50 70% + P95 30%)** 시 Pro 저 평균 원가 ≈ ₩19.9×0.7 + ₩84×0.3 = ₩39.1 → **약 37턴/월**.
- **권고**: fair-use 한도를 P95 기준 보수 설정. Pro = 월 **30~40턴** (₩9,900대 권장, ₩4,900은 위험), Premium = 월 **70~120턴** (₩12,900~19,900). 한도 소진 시 throttle 또는 종량(디노미네이션 포인트) 전환.
- Pro를 ₩4,900으로 가려면 채팅을 **Haiku로 구동**(§5)하거나 한도를 P95 17턴으로 못박고 초과분 종량 강제해야 §0 유지.

## 핵심 질문 답변

**Q1. 채팅 P50/P95/P99 턴 원가는?** (가정 시나리오, 환율 ₩1,474)

| | Sonnet 4.6 | Haiku 4.5 |
|---|---|---|
| P50 (in1,500/out600) | ₩19.90 | ₩6.63 |
| P95 (in9,000/out2,000) | ₩84.02 | ₩28.01 |
| P99 (in16,000/out3,000) | ₩137.08 | ₩45.69 |

기존 ai-cost-table "채팅 ₩16.2 가정"은 RAG top 25 풀 적재를 반영 못 한 과소추정 — P50과 P90 사이 수준. **개정 권고**(단 실측 후, S Phase).

**Q2. §0 안전한 디노미네이션 비율은?** — 세 비율 모두 `ceil(원가×3 ÷ 1pt단가)` 차감 규칙이면 §0 안전(반올림 적자 구조적 불가). **1:1,000 권고** — 올림 오차 0.36% 이하, 표시 인지부담·표현력 균형 최적. 1:100은 짧은 턴 표현력 부족, 1:10,000은 표시 부담 과잉.

**Q3. 구독 fair-use 안전 월 채팅 한도는?** — **스트레스 P95 기준**: Pro ₩9,900 = 약 27~36턴/월, Premium ₩12,900 = 약 36~47턴/월, ₩19,900 = 약 57~74턴/월. **Pro ₩4,900은 P95 13~17턴으로 위험** — Haiku 구동 또는 초과 종량 강제 시에만 성립.

**Q4. "구독중심 + 디노미네이션" 조합이 §0을 깨지 않고 성립하는가?** — **조건부 PASS**. 성립 조건 4가지:
1. 디노미네이션 채팅 차감은 `ceil(AI원가 × 3 ÷ 1pt단가)` 규칙 강제 (floor/round 금지).
2. 채팅 1턴 토큰 실측 필드(`ChatMessage.inputTokens/outputTokens/model`)를 먼저 추가 — 실측 없이는 차감액 산정 불가.
3. 구독 fair-use 한도는 **스트레스 P95** 기준으로 고정. Pro는 ₩9,900대 권장(₩4,900은 Sonnet으로 불가).
4. 한도 초과분은 디노미네이션 포인트 종량으로 흡수(throttle 단독은 사용자 경험 손해 + 헤비 적자 미해결).
→ 4조건 충족 시 §0 ≥3.0× 유지. 미충족 시 헤비유저 적자(P95~P99 구간)로 **FAIL**.

**Q5. Haiku 4.5로 채팅 구동 시 여유는?** — AI 원가 67% 절감(Sonnet 대비 1/3). 동일 구독료에서 fair-use 한도가 **약 3배**로 확대: Pro 저 P95 17턴 → **51턴**, Pro 고 36턴 → **109턴**, Premium 고 74턴 → **224턴**. Haiku면 Pro ₩4,900도 P95 51턴으로 §0 안전하게 성립. **트레이드오프**: 채팅 품질(작품 맥락 추론·일관성)이 Sonnet 대비 하락 — 품질 검증은 본 시뮬 범위 밖(researcher/planner 영역). 모델 티어링(짧은 턴 Haiku / 긴 컨텍스트 Sonnet 라우팅)이 품질·원가 최적안.

### v2-§0. 단일 pt단가 일원화가 §0 산식에 일으키는 구조 변화

기존 v1은 패키지별 단가 차등을 전제로 "가장 보수적인 베스트 ₩0.1/pt"만 검증했다. **단일 일원화 시 모든 pt가 동일 가치 → 가장 불리한 조건이 모든 거래의 기준이 된다.** 즉 §0은 더 빡빡해진다.

**핵심 함정 — 수수료는 "충전 시점"에 빠진다.** 채팅 차감 `ceil(원가×3÷pt단가)`는 AI 원가만 ×3 보장하고 결제 수수료는 보장하지 않는다. §0 정본은 총원가 = AI원가 **+ 결제수수료**다. 따라서 §0이 성립하려면 둘 중 하나:

- **(가) pt단가 = "충전액에서 수수료를 뺀 순 수령액 ÷ pt수"로 정의** → 차감 ceil이 순수령 기준이 되어 수수료가 이미 반영됨. ✅ 권고.
- (나) pt단가 = 표면 충전액 ÷ pt수 → 차감식에 수수료를 별도로 더해야 함(코드 복잡 + 보너스 적용 시 깨짐). ❌ 비권고.

→ **v2는 (가) 채택.** 1pt단가는 "순 수령 가치"로 정의하고, 채팅 차감 = `ceil(AI원가 × 3 ÷ pt순단가)`.

### v2-A. 단일 pt단가 산출

**A-1. 기준 단가 후보.** 현 패키지 표면가는 베스트가 가장 싸다(₩0.1/pt 표면). 단일 일원화는 "가장 싼 pt도 §0를 통과해야 한다" → **베스트 기준(₩0.1/pt 표면)을 기준 단가로 고정**하면 기존 최저선과 호환되고, 인기/기본 구매자는 자동으로 더 안전.

**A-2. 표면단가 → 순단가 환산 (수수료 차감).** 보너스 0% 가정, 충전액 X원에 기본 pt = X/0.1 (= X×10 pt). Polar 수수료 = X×2.9% + ₩442.

| 충전액 | 기본 pt(표면 ₩0.1) | Polar 수수료 | 순 수령액 | **pt당 순단가** |
|---|---|---|---|---|
| ₩5,000 | 50,000 pt | ₩587 | ₩4,413 | **₩0.08826** |
| ₩10,000 | 100,000 pt | ₩732 | ₩9,268 | ₩0.09268 |
| ₩30,000 | 300,000 pt | ₩1,312 | ₩28,688 | ₩0.09563 |

> 고정수수료 ₩442가 소액 충전을 잠식 → 소액일수록 순단가 낮음(=플랫폼 불리). **₩5,000 충전이 최악 케이스**: 순단가 ₩0.08826/pt.

**A-3. 보너스율 상한.** 보너스 b는 같은 충전액에 pt를 더 줌 → **실효 순단가 = ₩0.08826 ÷ (1+b)**. 실효 순단가가 낮아질수록 채팅 차감 pt가 커지지만, 차감식이 `ceil(원가×3÷실효순단가)`인 한 §0은 항상 성립(올림은 사업자 유리). **즉 §0 게이트만 보면 보너스율에 수학적 상한이 없다.**

그러나 두 제약이 실질 상한을 만든다:
1. **고정 차감 N pt 정책을 쓸 경우(§C 권고)**: N은 충전 시점 결정 불가 → "기준 순단가"로 한 번 산출한 N을 모든 거래에 적용. 보너스 받은 pt도 같은 N으로 차감되므로, 보너스가 클수록 그 pt들의 실효 차감가치가 낮아진다. N을 **최악 순단가(₩0.08826)** 기준으로 잡고, 보너스 상한을 두지 않으면 보너스 pt 소비분에서 §0 미달. → **고정 N 정책에서는 보너스율 상한 필요.**
2. **마케팅 한계**: 보너스는 결국 할인. 베스트 패키지가 이미 기본 대비 4배 효율(₩0.4 vs ₩0.1)이었던 것을 보너스로 흡수.

**보너스율 상한 산출 (고정 N 정책 기준, §C·§G와 연동):** 채팅 1턴 고정 차감 N을 P95 스트레스 기준으로 박으면(§C·§G), N의 안전배수 여유분이 보너스를 흡수할 한도다. §C에서 P95 고정 차감 N=3,720pt(스트레스 기준)일 때 비스트레스 P95 실효배수는 약 3.65×. 이 여유(3.65/3.0 = 1.217)가 보너스가 잠식 가능한 최대치 → **보너스율 상한 ≈ +21%**. 안전하게 **상한 +20%로 권고**(베스트 패키지에만 부여, 기본·인기는 보너스 0).

**A-3 가정**: "+20%"는 §C 고정 N의 스트레스 여유분 역산값. 채팅 토큰 실측 후 N이 바뀌면 보너스 상한도 재산출 대상.

**A 권고**: **1pt 기준단가 = 표면 ₩0.1 / pt** (순단가 최악 ₩0.08826). 보너스율 상한 **+20%** (베스트 대용량 충전 한정). 동적 차감(`ceil`)을 쓰면 보너스 상한 불필요하나, §C 권고대로 고정 차감을 쓰므로 +20% 상한 적용.

|---|---|---|---|
| ⓐ 리셋 | 미사용 풀 매월 소멸 | **안전**. 월 budget이 절대 상한. 누적 불가 | 무력화 없음 |
| ⓑ 무제한 이월 | 미사용분 영구 누적 | **위험**. N개월 미사용 후 한 달에 몰아쓰면 그 달 원가 = N×budget → 그 달만 보면 §0 = (구독료−수수료)÷(N×budget×3) → **1/N로 붕괴** | **완전 무력화** |
| ⓒ 상한부 이월 | 이월 상한 = 월 풀의 K배 | 중간. 최대 누적 = (1+K)×풀 → 최악의 달 §0 배수 = 3.0 ÷ (1+K) | K배까지 완화 |

**D-2. 이월이 fair-use를 무력화하는 수치.** Pro budget ₩3,057. 채팅 스트레스 P95 원가 ₩109.39 → 월 fair-use 한도 = 3,057÷109.39 ≈ **28턴/월**.

- ⓑ 무제한 이월: 작가가 6개월 안 쓰다가 7개월째 몰아쓰면 누적 풀 = 7개월치 = 196턴 분량을 한 달에. 그 달 플랫폼 실 AI원가 = 196 × ₩109.39 = ₩21,440. 그 달 구독료 ₩9,171(순). **§0 배수 = 9,171 ÷ (21,440×3) = 0.14× → 완전 적자.** 누적 6개월이면 7배 적자.
- ⓒ 상한부(K=1, 즉 최대 2개월치): 최악의 달 56턴 = ₩6,126 원가. §0 = 9,171÷(6,126×3) = **0.50×** → 여전히 적자(이월분이 §0 마진을 안 갖고 들어옴).

**D-3. 핵심 — 이월분에는 §0 마진이 없다.** 구독료는 "그 달의 풀"에 대해 ×3 마진을 갖도록 설계됐다. 이월된 풀은 **이미 마진을 소진한 과거 구독료에서 왔는데 원가는 미래에 발생** → 이월 pt는 마진 0으로 들어온다. 따라서 **어떤 이월도 그 달 §0를 희석**한다.

**D 권고: ⓐ 매월 리셋.** 단 UX 보완:
- 구독 풀은 **리셋**(이월 없음) — fair-use 한도의 무결성 유지, §0 절대 안전.
- 미사용분 아쉬움은 "**충전 포인트는 영구 보존**"으로 흡수 — 작가가 풀을 다 못 쓸 것 같으면 충전 대신 구독만 쓰면 됨. 충전 pt는 이미 §0 마진을 품고 결제됐으므로 영구 보존해도 §0 중립.
- 이월을 꼭 줘야 한다면 ⓒ 상한부 K=0.5(최대 1.5개월치) **이하**, 그리고 그 경우 구독 budget을 이월 희석분만큼 낮춰 설계(=구독료 인상 또는 fair-use 한도 하향). 권고하지 않음.

**D 가정**: "6개월 미사용 후 몰아쓰기"는 극단 시나리오지만 무제한 이월의 구조적 취약점을 보이는 데 충분. 실제 이월 악용률은 운영 데이터 필요.

### v2-E. 포인트 출처별 §0 위상 (결함 1·5)

포인트 출처 4종의 §0 적용 방식과 소진 우선순위.

| 출처 | 매출 | §0 위상 | 비고 |
|---|---|---|---|
| ① 구독 풀 | 구독료(Pro/Premium) | budget = (구독료−수수료)÷3. fair-use 한도로 §0 강제 | 풀 리셋 시 안전(§D) |
| ② 충전(Polar) | 충전액 | pt 순단가에 §0 마진 선반영(§A 가). 차감 시 자동 충족 | 영구 보존 가능 |
| ③ 무료 적립(가입·첫작품) | **₩0 (매출 없음)** | §0 적용 **불가** — 판매단가 0. **마케팅 비용(CAC)으로 회계 분리** | 아래 E-1 |
| ④ 독자 응원 선물 | 독자가 충전/구매한 pt 이전 | 독자 결제 시점에 이미 §0 충족. 작가에게 이전돼도 **§0 재검증 불요** | 아래 E-2 |

**E-1. 무료 적립의 §0 위상.** 무료 적립 pt는 판매수익이 0이므로 §0(판매 ≥ 원가×3)을 **수학적으로 절대 만족 못 한다**. 이것을 §0 위반으로 보면 안 된다 — **무료 적립은 §0 적용 대상이 아니라 마케팅 비용**이다. 회계 처리:
- 무료 적립 pt가 소비하는 AI 원가 = **고객 획득 비용(CAC)** 계정으로 분리 계상. 크레딧 매출 P&L에 섞지 않음.
- 리스크 = 무료 적립 총량 × pt당 AI원가가 마케팅 예산을 넘는 것. 가입 무료 적립을 채팅 P95 1턴(스트레스 ₩109)도 못 할 만큼 작게 주거나, 무료 적립은 **저원가 기능에만 사용 가능**하도록 제한(예: 무료 pt는 테마/짧은 채팅만, 긴 채팅·분석 불가)하면 CAC 상한 통제.
- **권고**: 무료 적립 pt에 **소비 용도 제한**(짧음 구간 채팅 + 테마까지) + 월별 무료적립 소진 AI원가를 COST_AUDIT_REPORT 마케팅 비용 줄에 별도 집계.

**E-2. 응원 선물의 §0 위상.** 독자가 자기 돈으로 충전/구매한 pt(§0 충족 완료)를 작가에게 선물. **pt는 이미 §0 마진을 품고 시스템에 들어왔으므로**, 작가가 그 pt를 쓸 때 §0 재검증 불필요 — 소유권만 이전됐을 뿐 마진은 보존. 단 주의 2건:
- 응원 선물에 플랫폼이 **보너스를 얹어주면**(예: "선물하면 +10%") 그 보너스분은 무료 적립과 동일 위상(매출 0) → E-1 처리.
- 선물 자체에 수수료(이전 수수료)를 물리지 않는 한 §0 중립. 결제가 개입하지 않는 순수 pt 이전은 추가 수수료 0.

**E-3. 소진 우선순위가 §0/회계에 주는 영향 — 핵심.** 한 작가가 4종 pt를 다 갖고 있을 때 **어느 pt부터 차감하느냐**가 §0·회계에 직결:

권고 소진 순서: **③ 무료 적립 → ① 구독 풀 → ④ 응원 선물 → ② 충전 pt**

근거:
- **무료 적립(③) 먼저 소진** — 가장 빨리 소진시켜 "유효기간 만료로 무료 pt 미사용 소멸"을 줄이고, 무료 pt를 저원가 용도로 일찍 태워 CAC 통제. 무료 pt에 만료를 둬야 부채 무한 누적 차단.
- **구독 풀(①) 그다음** — 월 리셋되므로(§D) 안 쓰면 소멸 → 충전 pt보다 먼저 태워야 작가 손해 없음. fair-use budget 안에서 소비되므로 §0 안전.
- **응원 선물(④) → 충전(②) 마지막** — 둘 다 §0 마진 보유분. 충전 pt를 가장 마지막에 둬야 "내 돈 주고 산 pt가 가장 오래 남는다" → 사용자 신뢰 + 충전 pt 영구보존 정책과 정합.
- **회계 영향**: 이 순서면 매 차감 건의 출처가 결정적 → COST_AUDIT_REPORT에서 "무료적립 소진 AI원가(=CAC)" vs "유료 pt 소진 AI원가(=COGS)"를 깔끔히 분리 집계 가능. 순서가 뒤섞이면 한 턴의 원가가 어느 계정인지 모호 → 마진 추적 불가.

**E 가정**: 무료 적립 만료기간·용도제한 범위는 planner 정책 결정 영역. 본 분석은 §0/회계 관점 권고만.

### v2-F. 디노미네이션 후 테마/분석 재산정 (단일 단가 기준)

v1 §5는 "안전배수 불변"이라 했으나 그건 패키지별 차등 단가 전제였다. **단일 단가 일원화 시 가장 불리한 순단가(₩0.08826/pt)가 모든 거래 기준** → 재확인 필요.

차감식 = `ceil(AI원가 × 3 ÷ 0.08826)`:

| 기능 | AI원가 | 원가×3 | 고정 차감 pt | 실효 차감액(표면 ₩0.1) | 안전배수(표면가 기준) |
|---|---|---|---|---|---|
| 테마 AI 생성 | ₩14.6 | ₩43.8 | **500 pt** | ₩50.0 | ₩50.0 ÷ (14.6+수수료 ₩5.9*) = **2.44×** ⚠️ |
| AI 작품 분석 | ₩60.4 | ₩181.2 | **2,060 pt** | ₩206.0 | ₩206.0 ÷ (60.4+수수료 ₩24.3*) = **2.43×** ⚠️ |

> *수수료 = 차감액에 대응하는 비례 수수료. ₩50 차감 → 해당 충전분 수수료 ≈ ₩50×(0.01174/0.1) = ₩5.87. 분석 ₩206 → ₩24.2.

**⚠️ F-1. 단일 단가의 함정.** `ceil(원가×3÷순단가)`는 **AI원가만 ×3** 보장하지 충전 수수료를 포함 안 한다. 순단가 ₩0.08826은 "₩5,000 충전" 수수료를 이미 흡수했지만, 그건 **충전 한 번의 수수료**고, 차감식의 분자는 AI원가뿐이라 수수료 마진 ×3이 빠진다.

**정정**: §A-§C의 차감식을 `ceil(AI원가 × 3 ÷ pt순단가)`로 쓰면 — pt순단가가 이미 수수료 차감 후 값이므로 — **차감액 자체가 "AI원가×3을 순가치로 회수"**한다. 즉 ₩50 순차감 = 순가치 ₩50 회수 ≥ AI원가 ₩14.6×3 = ₩43.8. **이게 맞다. 위 표의 "2.44×"는 표면가÷(원가+수수료)로 잘못 계산한 것** — 올바른 §0 판정은 **순회수액 ÷ AI원가**:
- 테마: 순회수 = 500pt × ₩0.08826 = ₩44.13 ÷ AI원가 ₩14.6 = **3.02×** ✅ PASS
- 분석: 순회수 = 2,060pt × ₩0.08826 = ₩181.8 ÷ AI원가 ₩60.4 = **3.01×** ✅ PASS

**F-2. 그러나 v1의 3.48~3.80×에서 3.0×로 마진이 깎였다.** 이유: v1은 패키지별 차등 단가라 베스트 구매자도 ₩100/크레딧을 냈고 수수료가 ₩11.7로 작았다. 단일 단가 일원화 + "₩5,000 충전 최악 순단가"를 기준 삼으면 마진이 정확히 ×3 경계로 내려온다. **단일 일원화의 대가 = 마진 쿠션 소멸.** 3.0×는 §0를 통과하나 **안전배수가 정확히 경계선**이라 스트레스에 취약(§G).

**F 권고**: 테마 = **520pt**, 분석 = **2,120pt**로 약간 상향(차감 pt를 ceil 경계보다 3% 여유). 그러면 테마 3.14× / 분석 3.10× → 스트레스 쿠션 확보. 또는 pt 기준단가를 표면 ₩0.11/pt로 잡아 전체 쿠션 부여(가격 인상이라 사용자 결정 영역).

**F 가정**: 테마 input/output(800/500), 분석 원가 ₩60.4는 ai-cost-table 정본값 그대로. 디노미네이션 자체는 중립이나 "단일 단가" 결정이 마진을 경계로 압축 — 이건 v1이 놓친 지점.

### v3-7. 차감 N 재산정 트리거 정의

고정 차감 N은 한 번 정하면 코드 배포 없이 못 바꾼다. N은 **스트레스 가정(Sonnet+20% × 환율+8.5% = 합성 1.302배)** 기준이라, 실측 원가가 스트레스 가정 원가를 초과하면 그 즉시 §0 위반. `AI_COST_MONITOR.md` / `sensor-cost-margin` 연동 트리거:

| 트리거 | 조건 | 조치 |
|---|---|---|
| **환율 단독** | USD/KRW가 **₩1,624.33** 도달(현 ₩1,497.08 대비 +8.5%) | 차감 N 전면 재산정 필수 |
| **모델가 단독** | Sonnet 4.6 input 또는 output이 **+20%** 도달($3.60 / $18.00) | 차감 N 전면 재산정 필수 |
| **합성 (선제)** | (모델 변동% + 환율 변동%) 누적이 **+25%** 도달 | 스트레스 여유 소진 전 선제 재산정 권고(경계선 운영이므로) |
| **임베딩** | text-embedding-3-small 단가 변동 | 분석 차감 pt만 재산정($0.041 원가 구성 영향) |

- 스트레스 합성 한계 = 1.302배(모델 1.20 × 환율 1.085). 누적 변동이 +30.2%에 도달하면 초장문 채팅이 정확히 3.00× → 그 직전 +25%에서 선제 재산정해야 안전.
- `AI_COST_MONITOR.md` §6 임계치(2%/5%/10%)와 별개 — §6은 가격 알림용, 본 트리거는 **차감 N 코드 변경 발동용**. researcher 스윕에서 누적 +25% 감지 시 cost-accountant에 차감 N 재산정 요청 핸드오프.
- 모델 교체(Haiku 티어링 도입 등) 시에도 N 전면 재산정 — 모델별 단가가 다르므로.
