## 1. 사슴악마 정본 시각 요소 인벤토리

### 1-1. 작가공간 (`/deerdevil/`)
- **히어로 섹션**: 작가명 + 작품 타이틀 타이포그래피
- **에피소드 카드 그리드**: 그리드 레이아웃, 카드 크기/간격, 썸네일 비율
- **시리즈 탭 네비게이션**: 탭 스타일, 활성/비활성 상태
- **Antler divider**: 섹션 간 구분선 (사슴뿔 형태)
- **PREFACE 섹션**: 작품 서문 배치

### 1-2. 에피소드 뷰어 (`/deerdevil/deerdevil/{ep}`)
- **타이핑 애니메이션**: 본문 텍스트가 한 글자씩 나타나는 효과
- **소제목**: 타이포그래피 계층
- **본문 렌더링**: 폰트, 줄 간격, 문단 간격
- **구분선**: 문단 내 구분선 스타일
- **이탤릭 처리**: 강조 텍스트 스타일
- **이전/다음 화 네비게이션**: 하단 버튼 배치

### 1-3. 에피소드 목록
- **가로 그리드 카드**: 카드 레이아웃
- **PREFACE 섹션**: 서문 영역

### 1-4. 핵심 CSS Variables (design-tokens.md 기준)
- 색상: bg, fg, accent, divider
- 타이포: 본문 폰트 패밀리, 사이즈 스케일, 웨이트
- 여백: padding/margin 스케일
- 애니메이션: 타이핑 속도, 트랜지션 지속시간

## 2. 정본 불일치 유형 (버그) — 6 카테고리

### 2-1. 구조적 불일치 (Critical)
- 작가공간에 히어로 섹션이 없음
- 에피소드 뷰어에 타이핑 애니메이션이 없음
- Antler divider 대신 일반 `<hr>` 사용
- 시리즈 탭이 작동하지 않음

### 2-2. 타이포그래피 불일치 (High)
- 본문 폰트가 정본과 다름
- 소제목 계층이 깨짐
- 이탤릭 처리가 정본 스타일과 다름
- 줄 간격 불일치

### 2-3. 색상 불일치 (High)
- 배경색/전경색이 정본과 다름
- Accent 색상 매핑 오류
- 다크/라이트 모드 반전

### 2-4. 애니메이션 불일치 (Medium)
- 타이핑 속도 다름
- 페이드 지속시간 다름
- 트랜지션 누락

### 2-5. 레이아웃 불일치 (Medium)
- 카드 간격 다름
- 그리드 컬럼 수 다름
- 반응형 브레이크포인트 다름

### 2-6. 에셋 불일치 (Low)
- Antler divider SVG 깨짐
- 썸네일 비율 다름
